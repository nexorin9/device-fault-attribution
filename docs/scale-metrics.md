# 簇引擎真实规模度量

| 项目 | 数值 |
|---|---|
| 语料条数 | 1200（corpus/scale.jsonl，含缺字段与重复行） |
| 运行机器 | Darwin arm64 / Python 3.13.12 / CPU 10 |
| 产品判定器 | `dfa-cli measure` → `dfa-cluster::engine::measure` |
| 度量时间口径 | `std::time::Instant` 实测单次逐 tick 差分耗时 |

| 指标 | 实测 | 验收阈值 | 结论 |
|---|---|---|---|
| 幂等键唯一数 / 总数 | 915 / 915 | 唯一性 = 100% | 通过（1.0000） |
| 簇内一致性（同键成员硬约束一致率） | 1.0000 | >= 99% | 通过 |
| 逐条回执完整率 | 1.0000 | = 100% | 通过 |
| 单轮差分耗时 | 0.192 ms | <= 200 ms / 1000 条 | 通过 |
| 内存驻留（结构估算） | 671032 字节 | 记录项 | 已落表 |

- 簇成员总数 915，语料总行数 1200；缺字段与重复行按「不可比 / 去重」分流，不计入簇成员。
- 确认预算断言（`max(新预算, 携带预算−1)` 在 >= 5 tick 序列恒成立）由 `cargo test -p dfa-cluster --test confirm_budget` 覆盖。
- 全部阈值断言：通过。
