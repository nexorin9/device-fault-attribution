# fixtures · 脱敏样例集与本地协议替身

> **仅测试数据层，不是最终对接面。** 院内真实端点本轮不可得；真实出站客户端与字段规范见 `crates/dfa-workorder/`，接入条件见项目 README「对接现有系统」。

| 文件 | 用途 | 覆盖的判定边界 |
|---|---|---|
| `devices_sample.json` | 设备台账样例（24 台） | 缺序列号 3 台 / 缺型号 1 台 / 缺固件 / 缺批次 / 同型号不同批次 / 同固件不同型号 / 同批次不同型号 / 跨科室同型号 |
| `workorders_sample.json` | 故障工单样例（17 条，含 1 条重复行） | 同型号同固件同批次 3 条主簇 / 四类组合 / 词表外描述 / 证据不全 / 型号冲突 / 缺序列号设备 / 重复工单 |
| `teams_sample.json` | 班组能力样例（4 个班组） | 能力集合有交集与差集，用于核查步骤排序与能力剔除断言 |
| `edge_cases.json` | 边界语料 | 生僻字 / GBK 与 UTF-8 混编 / 超长字段 / 空值 / 仅空白 / 非法字节转义 / 患者标识混入 |
| `workorder_stub/` | 本地协议替身 | 按真实字段规范校验 10 个必填字段、Bearer 与 Idempotency-Key；同键只产生一张单；可注入 5xx 失败 |

**样例标识一律占位**：设备号 `DEV-EXAMPLE-xx`、序列号 `SER-EXAMPLE-xxx`、批次 `LOT-EXAMPLE-xx`、固件 `FW-x.x.x-EXAMPLE`，禁止出现可被误认为真实的批次号、序列号、住院号或身份证号。
